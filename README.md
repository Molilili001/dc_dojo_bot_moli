# 🏛️ Discord Dojo Bot 使用说明

Discord Dojo Bot 是面向 Discord 社区的综合型机器人，提供道馆挑战玩法、论坛/帖子运营、成员与反馈监控、事件待办、跨 Bot 联动和维护工具。

本文档只介绍功能与使用方法，不包含代码实现细节。

---

## 功能总览

### 1. 道馆挑战与徽章

- 普通道馆挑战：成员通过挑战面板进入道馆答题，通关后获得对应徽章。
- 究极道馆挑战：高难度随机题库挑战，支持通关计时与排行榜。
- 徽章墙：成员可查看自己已获得的道馆徽章。
- 进度查询：成员可查看自己的挑战进度；有权限的管理员可查询指定成员进度。
- 毕业奖励：完成指定道馆数量或全部道馆后，可通过毕业面板领取奖励身份组。
- 失败冷却：挑战失败达到条件后会进入冷却，管理员可手动解除。

常用指令：

- `/我的进度`：查看自己的道馆挑战进度。
- `/我的徽章墙`：查看自己的徽章墙。
- `/排行榜`：查看究极道馆排行榜。
- `/查询道馆进度`：查询指定成员的道馆进度，需要对应权限。
- `/设置进度`：为成员设置道馆通过记录，需要对应权限。
- `/重置进度`：重置成员道馆进度，需要对应权限。
- `/解除处罚`：解除成员挑战冷却，需要对应权限。

### 2. 道馆与面板管理

- 创建、更新、删除、停业/开启道馆。
- 导出道馆配置，便于备份或迁移。
- 发布普通挑战面板、究极挑战面板、徽章墙面板、排行榜面板和毕业奖励面板。
- 更新已发布挑战面板的黑名单、奖励身份组、移除身份组、通关数量等设置。
- 查看服务器已发布的召唤面板列表。
- 支持为用户或身份组授予细分道馆管理权限。

常用指令：

- `/道馆 建造`：上传道馆配置文件创建道馆。
- `/道馆 更新`：上传配置文件更新已有道馆。
- `/道馆 删除`：删除道馆。
- `/道馆 列表`：查看服务器道馆列表。
- `/道馆 后门`：导出指定道馆配置。
- `/道馆 停业`：开启或停用指定道馆。
- `/面板列表`：查看已发布的道馆相关面板。
- `/召唤面板`：发布普通或究极道馆挑战入口。
- `/徽章墙`：发布徽章墙入口。
- `/排行榜`：发布究极道馆排行榜面板。
- `/毕业面板`：发布毕业奖励领取面板。
- `/更新面板`：更新普通挑战面板设置。
- `/设置馆主`：管理道馆相关指令权限。

### 3. 社区管理与跨 Bot 联动

- 道馆黑名单：限制指定用户或身份组参与挑战和领取奖励。
- 道馆封禁：限制指定用户参与挑战。
- 跨 Bot 联动：在多个机器人之间同步处罚、黑名单和相关处理记录。
- 自动监控：可监听指定机器人或频道中的处罚信息，并进行联动处理。
- 处罚留档：成员因联动处罚被清空进度时，可在进度查询中查看历史提示。

常用指令：

- `/道馆黑名单`：添加、移除、清空或查看道馆黑名单。
- `/道馆封禁`：添加、移除或查看挑战封禁名单。
- `/联动同步`：查看联动状态、强制同步、配置联动频道或切换联动开关。

### 4. 论坛新帖监控

- 监听论坛频道新帖。
- 可为发帖人自动添加身份组。
- 可在帖子内发送欢迎、提醒或 @指定身份组。
- 可把新帖提醒转发到其他文字频道，并附带帖子链接。
- 提供配置面板和使用说明/预设，便于管理员按论坛频道独立配置。
- 支持手动补发漏处理帖子的通知消息。

常用指令：

- `/帖子监控面板`：发布论坛新帖监控配置面板。
- `/补发帖子消息`：为指定帖子线程补发通知或 @身份组消息。

面板使用步骤：

1. 管理员运行 `/帖子监控面板`。
2. 在面板中选择要配置的论坛频道。
3. 点击“新增/更新配置”填写自动身份组、通知内容、@身份组内容或跨频道提醒设置。
4. 可点击“使用说明/预设”查看可复制的填写格式。
5. 如某个帖子漏处理，可使用 `/补发帖子消息` 补发。

### 5. 扫描监听提醒与回顶

- 支持全服、频道、分类和单个帖子的监听规则。
- 支持关键词、正则、包含、完全匹配等触发方式。
- 可自动回复、自定义回复、添加反应、删除触发消息或删除机器人回复。
- 支持贴主在自己的帖子内配置规则，也支持管理员统一配置全服或频道规则。
- 内置回顶用途：成员发送指定触发词后，机器人返回当前频道或帖子的首条消息链接。

常用指令：

- `/扫描监听提醒 状态`：查看当前功能开关、规则数量和启用范围。
- `/扫描监听提醒 配置`：打开服务器级配置面板，需要管理权限或授权。
- `/扫描监听提醒 帖子配置`：在帖子内打开贴内配置面板。
- `/扫描监听提醒 频道配置`：配置频道级或分类级规则。

使用提示：

- 管理员可先用 `/扫描监听提醒 配置` 设置总开关、贴主配置权限和默认冷却。
- 贴主可在帖子中使用 `/扫描监听提醒 帖子配置` 添加帖子专属提醒规则。
- 管理员可用 `/扫描监听提醒 频道配置` 为某个频道或分类统一添加规则。

### 6. 成员加入监控

- 统计服务器每日新成员加入数量。
- 达到阈值时向指定频道发送提醒。
- 支持设置通知用户、通知身份组、告警频道和每日结算时间。
- 支持查看当天统计和快速开关。

常用指令：

- `/成员监控 面板`：打开成员监控配置面板。
- `/成员监控 状态`：查看当前监控状态和今日统计。
- `/成员监控 开关`：快速启用或停用成员监控。

### 7. 反馈系统

- 可发布反馈面板，支持匿名反馈和实名反馈。
- 可指定反馈投递频道。
- 可通过身份组白名单限制谁能提交反馈。
- 支持基础频率限制，减少刷屏。

常用指令：

- `/召唤反馈面板`：发布反馈入口。
- `/反馈设置频道`：设置反馈接收频道。
- `/反馈白名单`：添加、移除、查看或清空可提交反馈的身份组。

### 8. 事件列表与提醒

- 支持个人事件列表和频道事件列表。
- 支持添加、编辑、删除、排序和查看事件。
- 支持倒计时提醒和每日提醒。
- 可设置监听频道，成员在监听频道发送关键词时机器人可展示事件列表。
- 管理员可授权指定用户或身份组使用事件指令。

常用指令：

- `/事件 添加`：添加个人或频道事件。
- `/事件 编辑`：编辑事件备注、状态或消息链接。
- `/事件 删除`：按序号删除事件，支持批量删除。
- `/事件 排序`：打开可视化排序。
- `/事件 列表`：查看个人或频道事件列表。
- `/事件 提醒`：设置倒计时或每日提醒。
- `/事件 设置监听频道`：添加或移除事件监听频道，需要管理员或开发者权限。
- `/事件 授权`：管理事件指令授权，需要管理员或开发者权限。

### 9. 管理员与开发者工具

- 机器人代发消息，可选择频道、图片附件和回复指定消息。
- 查看系统状态、资源占用和数据库统计。
- 下载当日日志。
- 热重载功能模块。
- 清理缓存、查看活跃挑战、强制同步命令。
- 向所有服务器发送公告。

常用指令：

- `/say`：让机器人代发消息。
- `/状态`：查看状态或下载今日日志，仅开发者可用。
- `/重载`：重载指定模块，仅开发者可用。
- `/调试`：执行调试操作，仅开发者可用。
- `/公告`：发送全局公告，仅开发者可用。

## 权限说明

- 普通成员：可使用挑战、个人进度、徽章墙、排行榜、反馈和已授权的事件功能。
- 贴主：在允许的情况下，可管理自己帖子内的扫描监听提醒规则。
- 馆主/授权身份组：可使用被授予的道馆管理、进度管理、面板管理或查询功能。
- 管理员：可配置论坛监控、成员监控、反馈、事件授权和大多数服务器级功能。
- 开发者：可使用维护、调试、热重载、日志和全局公告等工具。

## 使用方法

### 1. 准备 Discord 机器人

1. 在 Discord Developer Portal 创建应用并添加 Bot。
2. 开启需要的 Intents：Server Members Intent、Message Content Intent。
3. 邀请机器人进入服务器，并授予所需权限，例如查看频道、发送消息、管理身份组、读取消息历史、管理消息、使用斜杠命令等。

### 2. 安装与配置

1. 安装 Python 3.10 或更高版本。
2. 克隆本仓库到服务器或本地环境。
3. 安装 `requirements.txt` 中的依赖。
4. 复制 `config.example.json` 为 `config.json`。
5. 在 `config.json` 中填写 Bot Token、开发者 ID、反馈频道、联动监控频道等必要配置。
   `QUIZ_ELIGIBILITY_API_KEY` 必须替换为至少包含 32 个随机字节的无填充 base64url key；缺失、格式错误或强度不足时，道馆挑战 Cog 会保持未加载，其他功能仍可启动。
6. 如服务器访问 Discord 需要代理，可在配置中启用代理设置。

### 3. 启动机器人

1. 在项目目录中启动 `bot.py`。
2. 等待控制台显示机器人上线和命令同步完成。
3. 在 Discord 服务器中测试 `/状态` 或 `/我的进度` 等指令。

### 4. 初始配置建议

1. 使用 `/设置馆主` 给活动管理员或身份组授予道馆管理权限。
2. 使用 `/道馆 建造` 创建道馆。
3. 使用 `/召唤面板` 发布普通或究极挑战入口。
4. 使用 `/毕业面板` 设置通关奖励。
5. 使用 `/帖子监控面板` 配置论坛新帖自动处理。
6. 使用 `/成员监控 面板` 配置成员加入统计与提醒。
7. 使用 `/召唤反馈面板` 发布反馈入口。
8. 使用 `/事件 授权` 给需要使用事件功能的成员或身份组授权。

## 运行注意事项

- 请勿提交真实的 `config.json`、数据库文件、日志文件或备份文件。
- 机器人需要足够高的身份组位置，才能给成员添加或移除目标身份组。
- 新增或修改斜杠命令后，可能需要等待 Discord 同步，或由开发者使用 `/调试` 的强制同步命令。
- 如论坛、成员监控或跨频道提醒无效，请先检查机器人在目标频道的查看、发送、读取历史和管理消息权限。
